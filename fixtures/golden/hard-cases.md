# Hard Cases

Inspired by Notion and Obsidian.

Works with Notion (beta).

Frontend (Vite)

Hosted on Vercel (free tier).

Thanks to the maintainers of Express.

Faster than Express in our benchmarks.

Not affiliated with React.

We love TypeScript (optional).

Built with Lodash.

Run `npm run build` to build.

Run `npm run deploy` to ship.

Use `yarn dev` while developing.

See [the guide](./docs/guide.md) for details.

See [the old guide](./docs/old.md).

Set DATABASE_URL before starting the server.

The server reads the port from the environment.

Requires Node 18 or newer.

Supports Windows, macOS and Linux.

Compatible with Express 4 middleware.

README CLEW 2 // CLAIM LEDGER

SCANNED -

Checks whether a GitHub README matches its code.

We read the README line by line. Code checks test each claim against the repo's package.json, scripts, files and env vars. Jev, an AI that only picks labels, sorts the lines rules can't. Claude Haiku writes the summary from the results. Neither AI decides what's true.

PUBLIC REPOS ONLY. SCANS ARE NEVER STORED.

THE FOUR BUCKETS

  • CONTRADICTEDThe README says it, the code disagrees.
  • MISSINGThe code does it, the README never mentions it.
  • UNVERIFIABLECan't be checked from code, or Jev wasn't sure.
  • VERIFIEDThe README and the code agree.

WHO DECIDED

  • DECIDED BY: RULEA fixed check read the line and tested it against the repo. Same input, same answer.
  • DECIDED BY: JEVNo rule could tell what kind of line it was, so Jev picked a label. Code still runs any check. Jev never decides what's true.
  • JEV CONFIDENCEOn rows that went to a code check, the bar shows how sure Jev is about what kind of line it is, not whether the claim is true. A row Jev kept away from a check says so in words: NOT A CHECKABLE CLAIM, with how sure Jev is of that, or THOUGHT, with the type Jev guessed and a number under the 0.8 bar.

LINKS TO THE README

Click L42 ↗ on any row to open that exact README line on GitHub. CODE ONLY rows have no README line, because the code does it and the README never mentions it.

HOW IT WORKS

  1. 1. RULESCode reads the README line by line and tests each claim against the repo: package.json, scripts, files and env vars.
  2. 2. JEV LABELSJev, an AI that only picks labels, sorts the lines rules can't. It never decides what's true.
  3. 3. HAIKU EXPLAINSClaude Haiku writes the summary from the results. Neither AI decides what's true.

LIMITS

  • JS/TS ONLYpackage.json holds both the packages and the commands, so it gives the checks something solid to test against. Other languages are planned, not built.
  • MONOREPOSReads pnpm-workspace.yaml and the workspaces field in package.json. Supports dir/* and exact dirs, up to 30 workspaces.
  • SIZEREADMEs over 50 KB are cut, and only the first 20 source files are read.
  • SCANS NEVER STOREDPublic repos only. Nothing about a scan is kept after it finishes.
  • ANALYTICSAnonymous page-view counts through Vercel Analytics. No cookies. Scans are never stored.
  • HAIKU CAN BE DOWNIf it is unavailable, the report still works and the clew speaks a fixed line.
